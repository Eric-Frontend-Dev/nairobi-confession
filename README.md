# 🏨 Nairobi Confession - Luxury Hotel Website

A modern and elegant luxury hotel website built with React. 
Designed to showcase hotel amenities, rooms, and services beautifully.

## 🚀 Features
- Elegant and responsive UI design
- Hotel rooms and amenities showcase
- Smooth navigation and layout
- Mobile friendly

## 🛠️ Tech Stack
- React
- CSS
- Vite

## 🔧 How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173`
